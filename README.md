# HBD — HomeBroker Data

Modern Python client for the BYMA Home Broker platform (Argentine stock brokers).

> **Status**: Alpha — under active development with strict TDD.

## Quick Start

```bash
# Development setup
uv venv --python 3.12 .venv
source .venv/bin/activate
uv pip install -e ".[dev]"

# Run tests
pytest
```
